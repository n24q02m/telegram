# better-telegram-mcp (renamed)

**This distribution has been renamed to [`n24q02m-telegram`](https://pypi.org/project/n24q02m-telegram/).**

`better-telegram-mcp` is now a transitional stub: installing it installs `n24q02m-telegram` and keeps the
legacy `better-telegram-mcp` command pointing at the same entry point, so existing
`uvx better-telegram-mcp` and `pip install better-telegram-mcp` setups keep working. Please switch to:

```bash
uvx n24q02m-telegram
pip install n24q02m-telegram
```

No further releases of `better-telegram-mcp` are planned beyond this stub. Source and issues:
https://github.com/n24q02m/telegram
